# Vinyl Tracker

[![CI](https://github.com/danielcoria/vinyl-tracker/actions/workflows/ci.yml/badge.svg)](https://github.com/danielcoria/vinyl-tracker/actions/workflows/ci.yml)

A diary for your record collection: track the vinyl you own, log what you play (side by side), and see your listening stats, forgotten records and stylus wear.

**Live demo: [vinyl-tracker-qu7q.onrender.com](https://vinyl-tracker-qu7q.onrender.com)** (sample data that resets on restart; the first visit after a quiet spell takes about a minute while the free server wakes up)
